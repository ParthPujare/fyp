Connect your apps (3 clicks, no tech needed)

Click 1 — Paste your key

  1. Open app.composio.dev → copy your API key.
  2. Here: Account → Integrations → Step 1 → paste → Save & check key.
  3. It tells you right away if the key works. Nothing else to copy — app logins are handled for you.

Click 2 — Connect

  1. Under Step 2 find your app (Gmail, GitHub, Slack…) — use search if needed.
  2. Press Connect → a login popup opens → log in with that app.
  3. Want an app that is not listed? Ask your admin to add it (Admin → Integrations → add toolkit name). No code changes.

Click 3 — Refresh, then chat

  1. Back here press Refresh next to the app → it turns active.
  2. Go to Chat and ask, e.g. check my mail.
  3. If the agent needs something not connected, it shows a Connect button right in chat — press it, Refresh, re-send.

If something looks wrong

  • Key rejected: copy it again from Composio — extra spaces break it.
  • Still pending: finish the popup login fully, then Refresh once more.
  • App missing: admin adds it once under Integrations → Catalog; everyone gets it.
  • Sending/making changes asks approval: normal — an admin approves it in Approvals.
