# Problem Statement

Enterprise AI assistants are being given direct access to internal systems, yet the only thing stopping a Marketing user from deleting HR records or running DevOps commands is the LLM's willingness to obey — a system prompt rule that is non-deterministic, unenforceable, and trivially bypassed by prompt injection. Agents run on blanket credentials, multi-step actions execute without deterministic gates or human approval, and memory leaks cross-user, cross-department knowledge with no check on who can read or write it. This project builds a **zero-trust harness** between the LLM and every tool, memory tier, and skill — enforcing role-based access, gating high-risk actions and central memory writes behind human approval, and recording every decision as auditable evidence — because access must be enforced in code, never trusted to a prompt.
